# Global marine fisheries catch database (1950–2014)

**Theme:** Environment / Fisheries / Marine resources  
**Coverage:** Global marine fisheries, 1950–2014  
**Unit of observation:** Spatial cell-year-country-taxon-gear records  
**Temporal granularity:** Annual  
**Format:** Large flat files / mapped catch-rate database described in an open-access article  
**Access:** [Nature Scientific Data article](https://www.nature.com/articles/sdata201739) — open access article; underlying dataset available in 5-year blocks  
**License:** Source data compiled from multiple public sources with use subject to source acknowledgements; article is open access  
**Last verified:** June 2026

***

## Key Variables

| Variable | Description |
|----------|-------------|
| year | Fishing year from 1950 to 2014.[page:1] |
| spatial cell | 30-minute global marine spatial cell with latitude, longitude, and ocean area information.[page:1] |
| fishing country | Reporting nation associated with the fishing activity.[page:1] |
| taxon | Accepted scientific and common name for the reported fished taxon.[page:1] |
| gear type | Fishing gear associated with the mapped catch record.[page:1] |
| large-scale catch rate | Estimated catch rate in tonnes per square kilometer per year for large-scale fishing.[page:1] |
| small-scale catch rate | Estimated catch rate for small-scale fisheries.[page:1] |
| illegal and unreported catch rate | Estimated illegal and otherwise unreported catch rate.[page:1] |
| discards | Estimated discard catch rates at sea.[page:1] |

## Notes & Quirks

This is a **real downloadable dataset**, not just a visualization. The article states that the complete dataset contains nearly 868 million records and is available in 5-year blocks starting from 1950.[page:1]

The records are mapped estimates derived from harmonized public fisheries sources rather than raw vessel-level observations. They combine reported landings with modeled spatial allocation, gear associations, illegal and unreported catch estimates, discards, and small-scale fishing estimates.[page:1]

The dataset is very large, so most users will need a database workflow or careful subsetting rather than opening files directly in a spreadsheet.[page:1]

Spatial precision varies with source quality, and the paper discourages using only a very small number of cells for inference.[page:1]

4. Download or request the underlying data in 5-year blocks as indicated in the article and associated resources.[page:1]
