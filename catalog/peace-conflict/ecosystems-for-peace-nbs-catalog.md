## Background

This catalog was developed by **PAX** (Dutch peacebuilding NGO) and **UNEP**, hosted on the **Ecosystems for Peace** platform — the online home of the Community of Practice on Environment, Climate, Conflict, and Peace (ECCP). It was formally presented at COP16 (Cali, 2024) and draws on a companion UNEP policy report, *Nature-based Solutions for Peace: Emerging Practice and Options for Policymakers*, which itself synthesizes 40 case studies and expert insights.[web:8][web:11][web:17]

The catalog's core purpose is to **inspire and inform decision-makers and programme managers** when designing climate and environmental security interventions in fragile and conflict-affected settings, by documenting real-world examples of NbS projects that have generated co-benefits for both ecosystems and peace.[web:8][web:13]

## What a Case Study Record Contains

Each of the 25 entries includes:

| Field | Description |
|-------|-------------|
| **Project title** | Full name of the NbS intervention |
| **Location** | Specific sub-national location and country |
| **Date range** | Implementation period (e.g., 2019–2021) |
| **Implementing organizations** | Lead agencies (e.g., FAO, UN Women, UN PBF, IUCN, NGOs) |
| **Short description** | Narrative overview of the intervention and context |
| **Type of NbS** | Category of nature-based solution applied (see below) |
| **Environmental aspects** | Which environmental dimensions the project addressed |
| **Human security aspects** | Human wellbeing and livelihood dimensions targeted |
| **Socio-political security aspects** | Conflict and peacebuilding dimensions addressed |
| **Scale** | Geographic scope (local/subnational/national/transboundary) |
| **Ecoregion** | Biome/ecosystem type of the project location |
| **Environmental goal** | Specific environmental outcomes targeted |
| **Peace goal** | Specific peace and security outcomes targeted |
| **Both goals** | Outcomes serving both environmental and peace objectives |
| **Good practices and challenges** | Qualitative lessons learned and implementation barriers |

## Potential Research Questions

- Across the 25 case studies, which combinations of NbS type and socio-political security aspect most frequently co-occur — and what does this suggest about which interventions are most evidence-backed for conflict-affected settings?
- Do projects targeting land rights & tenure and forced displacement tend to achieve stronger environmental or peace outcomes, and what implementation factors seem to matter?
- How do scale (local vs. transboundary) and ecoregion interact with the type of peace outcomes achieved — e.g., do transboundary water-related NbS more often produce shared governance outcomes?
- Can this catalog serve as a qualitative complement to quantitative ACLED or UCDP data — for instance, to identify whether conflict event locations overlap with regions where NbS interventions have been attempted?
- Which implementing organizations appear most frequently, and in which regions and NbS types — useful for understanding the institutional landscape of environmental peacebuilding for funding or partnership research?
- How does the geographic distribution of case studies map onto UNEP Strata's environmental stress hotspots or the Fragile States Index — are the most vulnerable regions covered?

## Notes & Quirks

- **25 cases is a small N** — this is a qualitative/practitioner catalog, not a statistical dataset. It is best used as a structured evidence base for qualitative comparative analysis (QCA), systematic case review, or policy illustration, rather than regression analysis.
- The catalog is **actively growing**: PAX and UNEP invite new submissions via a questionnaire on the platform, so the number of entries will increase over time. Always check the current count on the site.
- Each case study has varying depth of documentation — some include detailed good practices and implementation lessons while others are more summary-level. Not all fields are consistently populated across all 25 entries.
- The platform includes an explicit **conflict-sensitivity caveat**: NbS can carry risks including land grabbing, militarised conservation, and insufficient attention to justice. The catalog reflects conflict-sensitive implementation examples but does not evaluate or rate them quantitatively.
- A companion **Decision Tool** is accessible from the homepage to help practitioners unfamiliar with NbS navigate toward relevant case examples based on their context.
- The **"More Information"** section of the platform includes a curated reading list and practitioner toolkits from IUCN, IFRC, International Alert, UNEP, IISD, and others — a useful secondary bibliography for literature review.
- The platform is **bilingual (EN/ES)**, which is relevant for case studies from Latin America.
- A **downloadable spreadsheet** of the full database is available from the catalog interface — useful for offline analysis and integration into your own datasets.
- The **Technical Documentation PDF** (July 2024) explains the methodology used to select and structure case studies: https://solutions.ecosystemforpeace.org/wp-content/uploads/2024/07/2024-07-30-Technical-note-NbS-catalogue_v4.pdf

## How to Access

1. Navigate to https://solutions.ecosystemforpeace.org
2. Toggle between **Map** (geographic view) and **Tiles** (card grid view) using the View toggle
3. Use the 9 filter dropdowns to narrow by NbS type, environmental aspect, human/socio-political security aspect, continent, ecoregion, scale, and targeted outcome
4. Click any case study tile or map pin to read the full project record
5. Use the **Download** option to export the full database as a spreadsheet
6. Visit the **More Information** page for background on NbS for peace and practitioner toolkits
7. Use the **Decision Tool** button if you need help identifying relevant case types for a specific context
